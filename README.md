# CoursePilot

> 多平台网课**播放托管**助手 —— 倍速突破 · 自动续播 · 自动下一节 · 图文/资料自动阅读，全部状态摊开在一个可拖动的悬浮面板上。

![Version](https://img.shields.io/badge/version-2.1.0-blue)
![Author](https://img.shields.io/badge/author-Tiwing-green)
![Platform](https://img.shields.io/badge/platform-Chrome%20%7C%20Edge%20%7C%20Tampermonkey-orange)
![License](https://img.shields.io/badge/license-个人学习使用-lightgrey)

雨课堂、智慧树、智慧职教、学堂在线、超星学习通、中国大学 MOOC……每个平台的网课页面都长不一样，但你要做的事情是一样的：**把课看完**。CoursePilot 把这件事托管给引擎——你设定倍速，它负责播放、续播、读完图文资料、切下一节，并把每一个动作写进日志给你看。

- **两种装法**：Chrome/Edge 扩展（`dist/extension/`，不需要油猴）或油猴脚本（`dist/coursepilot.user.js`），共用同一份构建产物
- **交互界面**：Shadow DOM 悬浮面板，三页签（概览 / 设置 / 日志），位置与配置持久化
- **适配平台**：8 个国内主流网课平台开箱即用，未登记站点走通用 HTML5 策略

## 功能亮点

### 播放托管

| 功能 | 说明 |
| --- | --- |
| 倍速突破 | 平台 UI 只开放 2× 也能拉到 16×——在 `video` 实例上装 `playbackRate` 访问器，平台把速度写回 2× 时被拦下 |
| 倍速保持 | 平台把倍速重置回 1× 时，下一次轮询（默认 1 秒）自动补写 |
| 雨课堂专用适配 | 直接写入 `xt-speedbutton` 菜单并同步 `options.isDrag`，而不是硬改 `video.playbackRate` |
| 自动续播 | 视频被暂停（切页、缓冲、平台暂停）时自动 `play()` |
| 卡顿降档 | 连续 3 秒播放无推进时按 16→12→10→8 阶梯回退，日志写明原因 |
| 自动下一节 | 进度达阈值后按设定延迟切换；「下一节」按钮五级识别（选择器 → 文案 → 可点击元素 → 目录顺序 → 图标特征） |
| 点击校验 | 点完没反应自动降级为目录跳转，不再"日志说已切换、页面没动" |
| 指定"下一节"按钮 | 自动识别不了时手动拾取一次，选择器持久化（仅在真实内容页生效） |
| 弹题保护 | 检测到答题弹窗立刻暂停一切自动动作，处理完再继续 |
| 课程终点 | 目录全部完成后停止一切自动点击，绝不误点「返回/退出/回到首页」 |
| 导航安全边界 | 引擎的自动点击若把页面带回列表/首页，8 秒内自动回退——**离开课程只有你手动点才可以** |

### 内容自动识别

同一套引擎按页判断内容类型：**视频**（有可见视频）→ **图文**（有阅读容器）→ **资料**（附件入口），状态条实时显示。

- 图文/文档按设定节奏自动滚动（1× = 16 px/s），读到底自动进入下一节
- PDF 预览改为**停留计时**，计满即算已读
- 资料页只认带文件语义的入口，自动点「预览」打开阅读（**不下载**，下载是可选按钮）
- 任务列表页（未完成 / 学习日志）自动展开模块、点进未读小节，跳过作业/考核类条目

### 课程目录

- 扫描目录完成标记，面板显示「未完成：章节名」与完成度
- 全自动模式：列表页直接点进第一个未读小节，视频/图文/资料做完自动回退到目录跳转
- 防死循环：同节 15 秒内不重复点、两次跳转至少隔 8 秒、连续不生效就停手

### 可视化

- 悬浮面板：平台标识、状态、进度条、会话统计（已看时长 / 完成节数 / 实际倍率 / 累计切换）
- 永远置顶：`popover` 进入浏览器 top layer，不吃站点 `z-index`，全屏时自动跟随
- 倍速滑杆 0.5×–16× + 9 个预设按钮；设置页 10 个开关；日志页逐条记录关键事件
- 可拖动、可折叠、关闭后可恢复

## 边界声明（请先读）

CoursePilot 只做**播放节奏托管**，刻意不做以下事情：

| 不做 | 原因 |
| --- | --- |
| 不自动答题、不提交作业 | 学习结果的真实性由你自己负责 |
| 不改平台接口、不伪造进度上报 | 进度仍由平台播放器按原生逻辑上报，脚本只调整播放速度 |
| 不跳转视频时间轴（seek） | 跳转会被平台判定异常，且会让进度记录失真 |
| 不绕过人脸识别、拍照签到、防作弊检测 | 这类环节必须本人完成 |
| 不多账号批量、不代理登录 | 不做账号规模化操作 |
| 不参与讨论区、不提交实操作业 | 这两类需要本人判断与操作，明确不在范围内 |

**默认只改 `playbackRate` 与"继续播放/下一节"两个动作**，进度是否计入完全取决于平台自身的规则。倍速过高（部分平台 > 4×）可能触发平台风控或静音，请自行评估使用场景并遵守所在院校与平台的规定。

## 安装

### 方式一：浏览器扩展（不需要油猴）

适用于 Chrome / Edge 111+，无需任何脚本管理器。

1. 打开 `chrome://extensions/`（Edge 是 `edge://extensions/`）
2. 右上角打开「开发者模式」
3. 点击「加载已解压的扩展程序」，选择 `dist/extension/` 目录
4. 打开课程页，识别到课程内容时面板自动出现；未登记站点可点工具栏图标强制启动

> 扩展版配置存在站点自己的 localStorage（每站一份），脚本运行在页面主世界（`world: "MAIN"`），因此能读到雨课堂的 `__vue__` 与页面 jQuery——这也是它要求 Chrome 111+ 的原因。

### 方式二：油猴脚本

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（Violentmonkey 同样可用）
2. Tampermonkey 管理面板 → 添加新脚本 → 粘贴 `dist/coursepilot.user.js` 全文 → 保存
3. 打开课程页，识别到课程内容时面板自动出现

> 脚本只在已登记平台的页面激活；其他站点需自行加一行 `// @match`。

### 方式三：本地 Demo

```bash
npm run demo          # 启动 http://localhost:8123/demo/
```

Demo 用模拟播放器复刻课程页结构（含"下一节"按钮与"模拟弹题"），可完整看到面板工作过程，不接触任何真实平台数据。

### 方式四：控制台手动注入

已安装脚本（或扩展）后，可在任意页面执行：

```js
CoursePilotBootstrap({ force: true });
```

## 面板用法

| 区域 | 说明 |
| --- | --- |
| 顶部状态条 | 圆点颜色 = 状态：青色托管中 / 琥珀色弹题中断 / 红色异常 / 紫色本节完成 |
| 进度条 | 当前视频进度，右侧是 `当前时间 / 总时长` 与站点域名 |
| 暂停托管 | 关闭后不再下发倍速，视频维持原速，面板保留 |
| 下一节 | 手动触发一次"下一节"点击（与自动逻辑完全一致） |
| 倍速滑杆 | 0.5×–16×，步进 0.25；突破模式下标题旁显示「突破上限」标记 |
| 倍速预设 | 一键切换 1×–16×；超过 4× 时浏览器会静音，日志有提示 |
| 内容类型 | 状态条左侧小标签：视频 / 图文 / 资料，随页面自动切换 |
| 课程目录 | 识别到目录时显示「未完成：章节名」+「跳过去」；全部完成显示 `目录已完成 12/12` |
| 课件资料 | 识别到附件时显示「课件资料 N 项 · 阅读即可计入」，右侧可选下载按钮 |
| 阅读节奏 | 图文模式下倍速控件自动改名，数值表示滚动速度（4× = 64 px/s） |
| 设置页 | 10 个开关 + 完成阈值 / 下一节延迟 / 资料停留时长 / 指定"下一节"按钮 |
| 日志页 | 记录平台识别、视频锁定、倍速失败、弹题、切换等关键事件 |

面板可拖到任意位置，折叠后只留一条状态栏；关闭后通过油猴菜单（扩展版点工具栏图标）恢复。

## 控制台 API

```js
window.coursepilot.state();        // 当前完整状态快照
window.coursepilot.setSpeed(6);    // 改倍速
window.coursepilot.toggle();       // 暂停 / 继续托管
window.coursepilot.next();         // 手动下一节
window.coursepilot.config.get();   // 读取配置
window.coursepilot.log.entries();  // 读取日志
window.coursepilot.report();       // 一键诊断：目录候选 + 下一节候选 + 当前状态
window.coursepilot.destroy();      // 卸载面板并恢复原倍速
```

## 开发

```bash
npm run build   # 源码 → dist/coursepilot.user.js + dist/extension/（构建期编译校验）
npm run check   # node --check 关键文件
npm run demo    # 本地启动模拟课程页
```

一次构建出两个产物：油猴脚本与扩展目录（清单、图标、后台脚本由构建生成，图标是零依赖 PNG 编码器现画的）。源码是标准 ESM，`build.mjs` 用零依赖逻辑按依赖顺序拼进同一作用域并剥掉 `import` / `export`，**不需要打包器**；拼接后同名声明会冲突，所以构建脚本先 `new vm.Script(source)` 编译一次把冲突挡在提交前。

```
CoursePilot/
├── src/
│   ├── version.js            常量
│   ├── util.js               格式化 / 数值裁剪 / 配置合并
│   ├── log.js                环形日志
│   ├── config.js             配置 schema + 持久化仓库
│   ├── dom.js                跨 iframe / Shadow DOM 探测（节点预算 + 400ms 缓存）
│   ├── media.js              原生倍速读写、媒体状态快照
│   ├── engine.js             托管引擎（状态机 + 轮询主循环）
│   ├── platforms/
│   │   ├── base.js           通用适配器
│   │   ├── profiles.js       平台矩阵（新增平台改这里）
│   │   ├── xtplayer.js       雨课堂 / 学堂在线专用适配
│   │   └── index.js          profile × quirk 组合
│   ├── ui/
│   │   ├── styles.js         面板样式
│   │   └── panel.js          面板结构与交互
│   ├── api.js                window.coursepilot
│   └── main.js               启动、存储、油猴菜单
├── extension/background.js   扩展后台（工具栏点击 → 注入 / 开面板）
├── scripts/make-icons.mjs    零依赖 PNG 图标生成
├── dist/
│   ├── coursepilot.user.js   油猴脚本（可直接安装）
│   └── extension/            扩展目录
├── demo/                     模拟课程页
└── docs/                     架构与平台适配说明
```

引擎设计要点见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 已知限制

1. **真机验证覆盖有限**：雨课堂新版学习页已真机验证（含视频/图文/资料自动切换）；其余平台逻辑由 Demo 页验证，选择器随平台改版可能失效。
2. **选择器是启发式的**：站点改版后可能误判，日志里能看到命中的选择器。
3. **跨域 iframe 无法控制**：脚本只在顶层页运行；跨域播放器需要在那个域里单独放行。
4. **仍受浏览器自动播放策略约束**：首次需要用户手势，之后才能自动续播。
5. **不保证计入进度**：脚本不修改任何上报数据；部分平台对单次进度增量有上限，16× 下可能出现"视频在走但平台进度条停滞"，降到 5×–8× 通常更稳。
6. **高倍速会静音**：多数浏览器 > 4× 时静音，这是浏览器行为。
7. **突破上限后平台 UI 不会同步**：以面板显示与 `video.playbackRate` 为准；Canvas / WebRTC 自绘画面的播放器无法突破。
8. **扩展仅支持 Chrome / Edge 111+**：Firefox 请用油猴版。
9. **扩展未上架商店**：以开发者模式加载，清理扩展后需重新加载。
10. **`<video>` 原生全屏时面板盖不上去**：这是浏览器渲染限制，用"网页全屏"替代。
11. **`popover` 需 Chrome/Edge 114+**：更旧版本退回最高 z-index 方案。
12. **PDF 原生查看器无法滚动**：跨源文档只能停留计时，不能翻页。
13. **阅读是否计入取决于平台**：若平台要求点"已读完"或服务端心跳校验，脚本不会替你伪造。
14. **批量下载会触发浏览器确认**：允许一次即可。
15. **目录跳转依赖完成标记**：站点完全不标记完成状态时不会盲跳；补选择器方法见「诊断」日志。
