# CoursePilot

多平台网课**播放托管**助手：把课程视频按你设定的倍速播放、被平台暂停时自动续播、一节播完自动进入下一节，并用一个可拖动的悬浮面板把状态、进度、设置和日志都摊开给你看。

- 两种装法：**Chrome/Edge 扩展**（`dist/extension/`，不需要油猴）或 **油猴脚本**（`dist/coursepilot.user.js`），共用同一份构建产物
- 交互界面：Shadow DOM 悬浮面板，三页签（概览 / 设置 / 日志），位置与配置持久化
- 适配平台：雨课堂、学堂在线、智慧树、智慧职教、超星学习通、中国大学 MOOC、国家智慧教育平台、国家开放大学，未登记站点走通用 HTML5 策略

## 边界声明（请先读）

CoursePilot 只做**播放节奏托管**，刻意不做以下事情：

| 不做 | 原因 |
| --- | --- |
| 不自动答题、不提交作业 | 学习结果的真实性由你自己负责 |
| 不改平台接口、不伪造进度上报 | 进度仍由平台播放器按原生逻辑上报，脚本只调整播放速度 |
| 不跳转视频时间轴（seek） | 跳转会被平台判定异常，且会让进度记录失真 |
| 不绕过人脸识别、拍照签到、防作弊检测 | 这类环节必须本人完成 |
| 不多账号批量、不代理登录 | 不做账号规模化操作 |
| 不参与讨论区、不提交实操作业 | 这两类需要本人判断与操作，明确不在范围内 |

**默认只改 `playbackRate` 与"继续播放/下一节"两个动作**，因此进度是否计入完全取决于平台自身的规则；倍速过高（部分平台 > 4×）可能触发平台的风控或静音，请自行评估使用场景并遵守所在院校与平台的规定。

## 功能

**播放托管**

- 倍速突破：平台 UI 只开放 2× 也能拉到 5× / 10×——在 `video` 实例上装一层 `playbackRate` 访问器，平台播放器把自己内部状态写回 2× 时会被拦下，真实倍速保持不变（开关可关）
- 倍速下发与保持：平台把倍速重置回 1× 时，下一次轮询（默认 1 秒）自动补写
- 雨课堂 / 学堂在线专用适配：直接写入 `xt-speedbutton` 菜单并同步 `options.isDrag`，而不是硬改 `video.playbackRate`
- 自动续播：视频被暂停（切页、缓冲结束、平台暂停）时自动 `play()`，被浏览器自动播放策略拦截时只提示一次
- 卡顿降档：连续 3 秒播放无推进（16× 常见于解码/带宽跟不上）时自动按 16→12→10→8 阶梯回退，日志写明原因，不再干等
- 自动下一节：进度达到阈值后按设定延迟切到下一节，延迟用于给平台上报进度留窗口
- 「下一节」五级识别：平台选择器 → 按钮文案（button/a）→ 可点击的 div/span → 平台目录顺序（雨课堂新版学习页按 `is-active` 点下一项）→ class/id/aria 含 `next` / `arrow-right` 的图标按钮；全部失败则在日志列出候选按钮
- 点击校验：点完「下一节」后 4 秒内 URL / 标题 / 视频源都没变化，自动降级为课程目录跳转（未完成小节 → 目录顺序），不再出现"日志说已切换、页面没动"的死等
- 跳转兜底：点目录项后 2.5 秒页面没变化，依次尝试「目录项 `href` 直达」→「按 `node_id` 改写当前地址」（雨课堂这种 SPA 用 `node_id` 定位小节）；仍失败则日志写明该行可能需要点击整行
- 点击目标轮换：同一个小节反复点不动时，会依次切换点击「标题链接 → 整行 → 行内节点」，不再对着同一个元素空点
- **指定“下一节”按钮**：自动识别不了时，设置页点「点我，再点页面上的“下一节”」，然后在页面上点一次真实箭头，选择器会被记住（持久化），之后自动流程优先点它
- 弹题保护：检测到答题弹窗时立刻进入 `blocked` 状态，停掉所有自动动作，等你处理完再继续
- 课程终点：目录全部完成后进入 `done`，停止一切自动点击；目录里的「返回 / 退出 / 回到首页」入口会被过滤，绝不会被当成下一节点

**内容自动识别**

- 同一套引擎按页判断内容类型：有可见视频 → **视频**；无视频但有阅读容器 → **图文**；只有附件入口 → **资料**。状态条直接显示当前类型
- 图文 / 文档：按设定节奏自动向下滚动（1× = 16 px/s，4× = 64 px/s），读到底后按延迟自动进入下一节；平台选择器没覆盖时，会按“面积最大的可滚动主区域”找到内层滚动容器（PDF 预览、文档阅读器常见）
- PDF 预览：浏览器内置 PDF 阅读器（cross-origin embed / iframe）脚本无法滚动，改为**停留计时**——面板显示 `PDF 预览 · 8/15s`，计满即算已读并自动进入下一节，不需要手动翻阅
- 资料页：只认**带文件语义**的入口（`.pdf/.docx/.zip` 后缀、`download/attach/file` 语义、`download` 属性或「下载」文案），自动点「预览 / 查看」打开阅读页（**不下载**），停留达到设定时长即计为已读；带「未读 / 已完成」状态的章节列表不会被当成资料
- 列表页优先跳转：当前页只是可滚动的章节列表、且目录里有未读项时，直接点进未读小节，不会停在列表页空滚
- 抗误判：`display:none` 的占位 `<video>` 会被跳过；视频存在但一直没就绪时回退到图文识别

**课程目录**

- 扫描课程目录：平台 `outline` 选择器，或 `catalog / chapter / section` 一类容器，读取每一项的完成标记（已学完 / 完成 / `finished` 类名 / 进度百分比）
- 面板显示「未完成：3.2 二叉树的遍历」与目录完成度，点「跳过去」立即跳转
- 默认全自动：页面没有可识别内容、或只是章节列表页时，直接点进第一个未读小节，不需要任何确认；视频 / 图文 / 资料做完但没有「下一节」按钮时同样回退到目录跳转
- 跳转点的是行内真实链接（`<a href>`），不是外层行容器；点击序列含 `pointerdown`，兼容只监听 pointer 事件的框架
- 防死循环：同一小节 15 秒内不重复点、两次跳转至少间隔 8 秒、连续点击不生效就停手
- 识别不到时点面板上的「诊断」，日志会列出候选容器、条目数与完成标记数，便于补选择器

**可视化**

- 悬浮面板：平台标识、状态、进度条、时间轴、4 个会话统计（已看时长 / 完成节数 / 实际倍率 / 累计切换）
- 永远置顶：面板以 `popover` 进入浏览器 top layer，不吃站点 `z-index`；进入全屏时自动把面板搬进全屏元素，退出再搬回
- 倍速控制：滑杆 0.5×–16× + 9 个预设按钮（1× / 1.5× / 2× / 3× / 4× / 5× / 8× / 10× / 16×）
- 设置页：突破上限、自动续播、自动下一节、弹题暂停、自动弹面板、完成阈值、下一节延迟
- 日志页：带级别的滚动日志，便于排查"为什么没生效"
- 拖动定位、折叠成小条、关闭后通过油猴菜单再打开

## 安装

两种方式装的是同一份代码，功能完全一致，按你能装哪种选一种即可。

### 方式一：浏览器扩展（不需要油猴）

适用于 Chrome / Edge 111 及以上，无需安装任何脚本管理器。

1. 打开 `chrome://extensions/`（Edge 是 `edge://extensions/`）
2. 右上角打开「开发者模式」
3. 点击「加载已解压的扩展程序」，选择 `dist/extension/` 目录
4. 打开课程视频页，面板会自动出现；未登记的站点可点工具栏的 CoursePilot 图标，在当前页强制启动

工具栏图标的行为：已运行 → 打开面板；未运行 → 注入脚本并强制启动。

扩展版与油猴版有两处差异：

- 配置存在**站点自己的 localStorage**（每个平台各一份），油猴版走 GM 存储（跨站点共享）
- 扩展版的脚本运行在页面主世界，因此能读到雨课堂的 `__vue__` 与页面 jQuery；这也是它必须 Chrome 111+ 的原因（`world: "MAIN"` 支持）

### 方式二：油猴脚本

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（Violentmonkey 同样可用）
2. 打开 Tampermonkey 管理面板 → 添加新脚本 → 粘贴 `dist/coursepilot.user.js` 全文 → 保存
3. 打开课程视频页，右下角会出现 CoursePilot 面板（首次发现视频时自动弹出）

脚本只在你打开已登记平台的页面时激活；未登记的站点需要自己加一行 `// @match`。

### 方式三：本地 Demo

```bash
npm run demo          # 启动 http://localhost:8123/demo/
```

Demo 用一个模拟播放器复刻课程页结构（含"下一节"按钮与"模拟弹题"），可以完整看到面板工作过程，不接触任何真实平台数据。

### 方式四：控制台手动注入

已安装脚本（或扩展）后，可在任意页面执行：

```js
CoursePilotBootstrap({ force: true });
```

## 面板用法

| 区域 | 说明 |
| --- | --- |
| 顶部状态条 | 圆点颜色 = 状态：青色托管中 / 琥珀色弹题中断 / 红色异常 / 紫色本节完成 |
| 进度条 | 当前视频进度，右侧是 `当前时间 / 总时长` 与站点域名 |
| 暂停托管 | 关闭后不再下发倍速，视频维持原速，面板保留 |
| 下一节 | 手动触发一次"下一节"点击（与自动下一节的查找逻辑完全一致） |
| 倍速滑杆 | 0.5×–16×，步进 0.25；松手即生效并写入配置。突破模式下标题旁显示「突破上限」标记 |
| 倍速预设 | 一键切换 1× 到 16×，含 5× / 8× / 10×；超过 4× 时浏览器会静音，日志有提示 |
| 内容类型 | 状态条左侧的小标签：视频 / 图文 / 资料，随页面自动切换 |
| 课程目录 | 识别到目录时出现「未完成：章节名」，右侧「跳过去」按钮；全部完成时显示 `目录已完成 12/12` |
| 课件资料 | 识别到附件时出现一行「课件资料 N 项 · 阅读即可计入」，右侧是可选的下载按钮 |
| 阅读节奏 | 图文模式下倍速控件自动改名为「阅读节奏」，数值表示滚动速度（4× = 64 px/s） |
| 设置页 | 10 个开关（突破上限 / 卡顿降档 / 图文阅读 / 资料预览 / 下载课件 / 自动续播 / 自动下一节 / 目录跳转 / 弹题暂停 / 自动弹面板）+ 完成阈值 / 下一节延迟 / 资料停留时长 / 指定“下一节”按钮 |
| 日志页 | 记录平台识别、视频锁定、倍速失败、弹题、切换等关键事件 |

面板可以拖到任意位置，折叠后只留一条状态栏；关闭后通过油猴菜单（扩展版点工具栏图标）恢复。

## 控制台 API

```js
window.coursepilot.state();        // 当前完整状态快照
window.coursepilot.setSpeed(6);    // 改倍速
window.coursepilot.toggle();       // 暂停 / 继续托管
window.coursepilot.next();         // 手动下一节
window.coursepilot.config.get();   // 读取配置
window.coursepilot.log.entries();  // 读取日志
window.coursepilot.report();       // 一键诊断：目录候选 + 下一节候选 + 当前状态（同时写日志）
window.coursepilot.destroy();      // 卸载面板并恢复原倍速
```

## 开发

```bash
npm run build   # 源码 → dist/coursepilot.user.js + dist/extension/（构建期编译校验，重名/语法错误直接失败）
npm run check   # node --check 关键文件
npm run demo    # 本地启动模拟课程页
```

一次构建出两个产物：油猴脚本 `dist/coursepilot.user.js` 与扩展目录 `dist/extension/`（清单、图标、后台脚本由构建生成，图标是零依赖 PNG 编码器现画的，仓库里不存二进制）。

源码是标准 ESM，`build.mjs` 用零依赖逻辑把它们按依赖顺序拼进同一作用域，并剥掉 `import` / `export`，因此**不需要打包器**。拼接后同名声明会冲突，所以构建脚本会先 `new vm.Script(source)` 编译一次，把冲突挡在提交前。

```

├── src/
│   ├── version.js            常量
│   ├── util.js               格式化 / 数值裁剪 / 配置合并
│   ├── log.js                环形日志
│   ├── config.js             配置 schema + 持久化仓库
│   ├── dom.js                跨 iframe / Shadow DOM 探测（带节点预算与 400ms 缓存）
│   ├── media.js              原生倍速读写、媒体状态快照
│   ├── engine.js             托管引擎（状态机 + 轮询主循环）
│   ├── platforms/
│   │   ├── base.js           通用适配器
```

## 已知限制

1. **真机验证覆盖有限**：雨课堂新版学习页已真机验证（含视频 / 图文 / 资料的自动切换）；其余平台逻辑由 Demo 页面验证，选择器随平台改版可能失效。
2. **选择器是启发式的**：`next` / `obstacle` 优先用精确选择器，找不到再按"下一节 / 下一课 / 继续学习"等文案匹配；站点改版后可能误判，日志里能看到命中的选择器。
3. **跨域 iframe 无法控制**：脚本用 `@noframes` 只在顶层页运行，同源 iframe 已覆盖；跨域播放器需要在那个域里单独放行。
4. **仍受浏览器自动播放策略约束**：首次需要用户手势，之后才能自动续播。
5. **不保证计入进度**：倍速与自动切换都是"加速观看"，平台是否认可由平台规则决定；脚本不会修改任何上报数据。部分平台对单次上报的进度增量有上限，16× 下可能出现"视频在走但平台进度条停滞"，降到 5×–8× 通常更稳。
6. **高倍速会静音**：多数浏览器在 > 4× 时静音，这是浏览器行为，不是脚本限制。
7. **突破上限后平台 UI 不会同步**：站点自带的倍速标签可能仍显示"2.0X"，实际以面板显示与 `video.playbackRate` 为准；另外极少数播放器用 Canvas / WebRTC 自绘画面，`playbackRate` 对它无效，这类平台无法突破。
8. **扩展仅支持 Chrome / Edge 111+**：依赖 MV3 的 `world: "MAIN"` 才能读到页面里的 Vue 实例与 jQuery；Firefox 的 MV3 尚未支持该字段，Firefox 请用油猴版。
9. **扩展未上架商店**：以「加载已解压的扩展程序」方式安装，重装浏览器或清理扩展后需要重新加载一次。
10. **播放器把 `<video>` 本身全屏时面板盖不上去**：浏览器此时只渲染 video 元素，任何覆盖层都无法显示；用播放器自带的"网页全屏"或把网页窗口最大化即可。
11. **`popover` 降级**：Chrome 114+ / Edge 114+ 才支持 top layer；更旧的版本自动退回"最高 z-index + fixed"，遇到站点自绘的极高层级浮层仍可能被盖住。
12. **PDF 原生查看器无法滚动**：如果站点用 `<iframe src="*.pdf">` 调起浏览器内置 PDF 阅读器，那是跨源文档，脚本无法控制；这类页面只能手动翻页。图片化的课件页不受影响。
13. **阅读是否计入取决于平台**：多数平台按"停留时长 + 滚动"判定图文阅读，自动滚动能满足；若平台用服务端心跳或点击"已读完"按钮，脚本不会替你点（那是伪造行为），需要你手动确认。
14. **资料是否计入仍取决于平台**：脚本的做法是"打开预览 + 停留足够时长"，符合多数平台按停留/浏览判定资料阅读的规则；如果某平台需要你点击"标记已读"或由服务端校验，脚本不会替你伪造这一步。
15. **批量下载会触发浏览器确认**：下载是可选动作，一次点多个附件时 Chrome 会弹"是否允许多个下载"，允许一次即可。
16. **目录跳转依赖完成标记**：站点若完全不标记完成状态（没有文案、没有类名、没有 `data-status`、没有进度），脚本不会盲跳，以免点错；此时面板显示「未识别到课程目录」，点「诊断」可看到候选容器明细，把正确的容器类名补进 `src/platforms/profiles.js` 的 `outline` 即可。
17. **跳转是模拟点击目录项**：若站点 hash 路由不重新渲染，可能需要再点一次「跳过去」或手动刷新页面。
